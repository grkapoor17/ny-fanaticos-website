# Player photos

Drop a photo here named after the player's `id` from `src/data/players.ts`:

```
gautam.jpg
onur.jpg
rev.jpg
avi.jpg
caleb.jpg
ben.jpg
vikram.jpg
sriram.jpg
varun.jpg
roger.jpg
miles.jpg
max.jpg
lucas.jpg
```

`.jpg`, `.jpeg`, `.png`, and `.webp` all work. No code changes needed — the
site picks up the file automatically on the next build/dev reload.

Portrait-ish crop works best (cards render at a 3:4 aspect ratio).
